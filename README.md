# Catch the Ball - Game Python 🎮

Game arkade 2D sederhana bertema menangkap bola yang jatuh dari atas layar. Proyek ini dibuat menggunakan modul bawaan Python (**Turtle**), sehingga **tidak memerlukan instalasi pustaka eksternal** tambahan seperti Pygame.

---

## 🚀 Fitur Game
* **Tanpa Ribet Install:** Menggunakan pustaka bawaan Python, jadi langsung bisa dimainkan.
* **Kontrol Mudah:** Mendukung tombol panah keyboard (`Kiri` / `Kanan`) serta tombol huruf (`A` / `D`).
* **Sistem Skor & Nyawa:** Kumpulkan skor sebanyak-banyaknya dengan batas 3 kali kesempatan gagal.
* **Mulai Ulang Otomatis (*Auto Restart*):** Game tidak langsung keluar saat nyawa habis, melainkan akan mereset skor dan permainan secara otomatis.
* **Kesulitan Progresif:** Bola akan meluncur dengan kecepatan yang sedikit bertambah secara bertahap setiap kali kamu berhasil menangkapnya.

---

## 🛠️ Cara Menjalankan

1. Pastikan komputer kamu sudah terinstal **Python**.
2. Simpan kode game ke dalam satu file bernama `cobagame.py`.
3. Buka Terminal (Mac/Linux) atau Command Prompt / PowerShell (Windows) di dalam folder tempat file tersebut disimpan.
4. Jalankan perintah berikut:
   ```bash
   python cobagame.py
